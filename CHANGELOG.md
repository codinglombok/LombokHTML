# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.2.0] — 2026-10-03

### Added
- Python, Go and PHP ports; all five ports run the same 228 shared vectors and the 7028 html5lib-tests tokenizer cases.
- WHATWG tokenizer for HTML content: every tokenizer state, script data escapes, DOCTYPE public/system identifiers, CDATA as an initial state, the attribute rule for named references.
- All 2231 WHATWG named character references (`data/entities.json`), generated into each port by `scripts/gen_ports.py`.
- `tokenize_state` for starting in RCDATA, RAWTEXT, script data, PLAINTEXT or CDATA.
- Selectors: `+` and `~` combinators, `|=`, `:first-child`, `:last-child`, `:only-child`, `:empty`, `:nth-child`, `:nth-last-child`, `:not`; invalid selectors return `BAD_SELECTOR` with an offset.
- Meta: `lang` and `canonical`; sanitizer policies with per-tag attributes and extra URL schemes.
- `vectors/htmlmodel.py`, an independent reference model, and `vectors/check_conformance.py`.

### Changed
- Tree construction follows the WHATWG rules for `p`, `li`, `dd`/`dt`, headings, `option`, `a`, table cells and rows, end tags of special elements and `</br>`.
- Serialization follows WHATWG; attribute values also escape `<` and `>` as before.
- Kept raw text elements (allowed through a policy) are written without content so sanitizing stays idempotent; `plaintext` is never kept.
- Selector matching uses per-query caches; positional pseudo-classes and sibling combinators are linear in the number of siblings.
- All case-insensitive comparisons are ASCII-only.
- Rust MSRV is 1.70; the crate stays `no_std` + `alloc`.

### Fixed
- Only common named references were decoded (`&Afr;` stayed as text); all 2231 WHATWG names are now decoded.
- Legacy references without `;` (`&copy 2026`, `&amp`) were not decoded.
- `&#x80;`-`&#x9F;` produced C1 controls instead of the WHATWG replacements (`&#x80;` is now U+20AC).
- Vector expectations were generated by the Rust port itself; they now come from an independent model and html5lib-tests.

### Removed
- `scripts/lombok-doctor-docs.sh` (replaced by `scripts/lombok-doctor.sh`), `vectors/gen_inputs.py`, the TypeScript `compat` module.

## [0.1.0] — 2026-10-01

Initial version: Rust reference and TypeScript port (not published to any registry).
